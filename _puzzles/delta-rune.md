rules:
  - name: Classic Sudoku
    desc: Every row, column and 3x3 box must contain every number from 1 to 9.
  - name: Arrows
    desc: Numbers along an arrow sum up to the total in the circled cell.
  - name: Palindrome Lines
    desc: Digits along a grey line read the same backwards and forwards.
  - name: Region Sum Lines
    desc: Box borders divide a blue line into multiple segments which have the same sum.
  - name: Renban
    desc: All digits along a purple line must form a consecutive sequence (in no specific order).
  - name: German Whispers
    desc: Every two consecutive digits along a green line must have a difference of at least 5.
  - name: Counting Circles
    desc: Any digit in a circle indicates exactly how many circles contain that digit (arrow circles are <u>NOT</u> included).
  - name: Kropki
    desc: Two digits separated by a white dot are consecutive; two digits separated by a black dot have a 1:2 ratio.
rules_de:
  - name: Klassisches Sudoku
    desc: Jede Zeile, jede Spalte und jedes 3x3-Block muss alle Zahlen von 1 bis 9 enthalten.
  - name: Pfeile
    desc: Die Zahlen entlang eines Pfeils ergeben in der Summe den Wert in der eingekreisten Zelle.
  - name: Palindrom
    desc: Ziffern entlang einer grauen Linie lesen sich vorwärts und rückwärts gleich.
  - name: Region Sum Lines
    desc: Die Grenzen der 3x3-Blöcke unterteilen eine blaue Linie in mehrere Abschnitte, die dieselbe Summe aufweisen. Verschiedene Linien können unterschiedliche Summen haben.
  - name: Renban
    desc: Alle Ziffern entlang einer violetten Linie müssen eine aufeinanderfolgende Zahlenfolge bilden (in beliebiger Reihenfolge).
  - name: German Whisper
    desc: Die Differenz zwischen zwei benachbarten Ziffern auf einer grünen Linie muss mindestens 5 betragen.
  - name: Counting Circles (Zählkreise)
    desc: Jede Ziffer in einem Kreis gibt genau an, in wie vielen Kreisen diese Ziffer enthalten ist (Pfeilkreise sind <u>NICHT</u> enthalten).
  - name: Kropki
    desc: Zwei durch einen weißen Punkt getrennte Ziffern sind aufeinanderfolgend; zwei durch einen schwarzen Punkt getrennte Ziffern stehen in einem Verhältnis von 1:2.
